# ZameenHub

ZameenHub is a MERN stack real estate platform for buying, selling, and renting properties like plots, commercial lands, flats, shops, PGs, and homes.

## Features

- User Authentication (JWT)
- Signup/Login with phone number
- Property Listing System
- Seller Details on Property Cards
- Buy & Rent Categories
- Responsive UI (Mobile + Desktop)
- Admin Property Management
- Property Search & Filters
- FAQ Section
- Professional Homepage UI
- Toast Notifications & Validation
- Cloudinary Image Upload
- MongoDB Database Integration
